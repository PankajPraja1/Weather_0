# weatherX

weatherX is a simple weather application for checking current weather conditions by searching for a city or location.

## Features

- Search for weather by city or location
- View current temperature and weather conditions
- Responsive interface for desktop and mobile devices

## Live Demo

[View weatherX](https://weatherx-eight.vercel.app)

> **Note:** The deployed demo searching for weather is currently unavailable because the free OpenWeather API has limited usage. This is an educational project.
